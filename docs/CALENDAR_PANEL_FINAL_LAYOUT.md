# 快捷键大日历最终布局

日期：2026-09-18。状态：已实施，验收结果见 `validation/CALENDAR_PANEL_VISUAL_REFINEMENT_2026-09-18.md`。

## 1. 适用范围

本文是快捷键大日历的现行布局依据，覆盖旧文档中 880/900/1081.46 pt 宽、按月份行数改高度、四卡事件区、事件贴底和左栏容器未同步等冲突规则。菜单栏小日历、日历数据、监控、快捷键注册及原生材质逻辑不变。

## 2. 设计结论

- 窗口基准内容尺寸为 **1013.70×580 pt**，宽高比约 1.748；用户拖动时所有尺寸使用同一个比例 `s`。
- 四边外边距各 50 pt；左栏 280 pt、栏间距 24 pt、右栏布局区 609.70 pt。
- 月历网格为 **560×384 pt**，在右栏布局区水平居中；每列 80 pt、每行 64 pt。固定绘制六行，切月和切年不改变窗口尺寸与位置。
- 左右标题共享 44 pt 标题带并保持基线一致。导航、星期和网格围绕同一中心轴排列。
- 左栏使用同一套 4/8 pt 间距节奏，从上向下依次排列日期标题、时间、日期附加信息、分隔线和事件，不使用弹性间隔。
- 事件预留三条容量并从顶部排列；一条占第一行，剩余容量留在下面。超过三条才使用同高的局部滚动区，隐藏滚动指示条且保留全部数据。

## 3. 精确尺寸（s=1）

### 3.1 窗口与两栏

| 项目 | 尺寸 |
|---|---:|
| 内容区 | 1013.70×580 pt |
| 四边外边距 | 50 pt |
| 左栏 | 280 pt |
| 栏间距 | 24 pt |
| 右栏布局区 | 609.70 pt |
| 月历网格 | 560 pt，居中 |

宽度恒等式：`50×2 + 280 + 24 + 609.70 = 1013.70`。系统阴影不计入内容尺寸；透明标题栏不得再次叠加 safe-area padding。

### 3.2 右侧月历

| 项目 | 尺寸 |
|---|---:|
| 标题带 | 44 pt |
| 标题后间距 | 12 pt |
| 星期带 | 32 pt，字号 16 pt medium |
| 星期后间距 | 8 pt |
| 日期格 | 80×64 pt |
| 日期字号 | 24 pt |
| 农历/节日字号 | 16 pt |
| 今天/选中圆 | 54 pt |
| 班休角标 | 18 pt，字号 12 pt |

右栏自然高度为 `44 + 12 + 32 + 8 + 64×6 = 480 pt`，与上下 50 pt 外边距合成 580 pt。列与行使用固定槽位。导航栏以 560 pt 日历网格为边界：左右导航组均宽 92 pt，月份标题宽 170 pt 并保持绝对居中；左组贴网格左端、右组贴网格右端。四个按钮命中区均为 44×44 pt，双箭头在外、单箭头在内。

事件区顶部位于左栏 261 pt，完整左栏流程高 421 pt。左栏在 480 pt 共同布局区内顶部对齐，剩余 59 pt 位于事件容量之后；不得插到农历和分隔线之间，也不得把单条事件推到底部。

事件卡高 48 pt、行间距 8 pt，三条共 160 pt。“全天”列与卡片垂直居中；节日和“节日（休）”保持两个独立事件。

## 4. 缩放和交互

- 唯一比例 `s = min(实际宽/1013.70, 实际高/580)`；窗口约束锁定 `1013.70:580`。
- 字体、间距、网格、圆形高亮、角标、事件卡和命中区全部乘 `s`。禁止只放大外框或使用模糊位图缩放。
- 每次打开回到今天并居中于鼠标所在屏幕；拖动结束保存比例，不保存位置或日期状态。
- 屏幕放不下时允许临时整体缩小，但不覆盖用户保存的比例。
- 切月、切年和事件数量变化均不改变窗口尺寸；不重建模型、事件提供者或时钟。

## 5. 验收

1. 基准尺寸为 1013.70×580；四边外边距均为 50 pt。
2. 左右标题基线误差不超过 1 个物理像素；月历网格相对 609.70 pt 右栏水平居中。
3. 六行日期的列宽 80、行高 64，无额外弹性空白；角标、提示点和选中圆不碰撞。
4. 一至三条事件均从事件区第一行开始且无滚动条；超过三条可访问全部内容。
5. 1×和 1.25×实际拖动过程中内容同步变化，点击命中位置正确，关闭再开恢复比例。
6. Release 构建与相关测试通过；用独立构建产物截图验证，不操作正式安装版本。
